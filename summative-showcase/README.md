# Front-End Web Development Summative Showcase

## 📁 Project Overview
This is a responsive multi-page portfolio website built as part of my Front-End Web Development summative assessment.

It includes:
- A landing (home) page
- An about page with skills section
- A contact page with a functional form and confirmation modal

## 🔧 Technologies Used
- HTML5 (semantic structure)
- CSS3 (custom styling, Flexbox layout, transitions)
- JavaScript (form validation, modal interaction)

## 💡 Features
- Responsive design using a mobile-first approach
- Semantic and accessible HTML elements
- Styled navigation menu across all pages
- Smooth transitions on buttons and modal popups
- Basic form validation using HTML5 and JavaScript
- Organized folder structure

## 🧪 Validation
- All HTML and CSS files pass W3C validation
- Keyboard-accessible navigation and forms
- Mobile layout tested using dev tools
